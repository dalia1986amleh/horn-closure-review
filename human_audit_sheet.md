# Human audit sheet: rules and answer keys

Please read each item and tick one box. About 20 minutes. All rules are in English; the words are invented, so only the logic matters.

The two rule forms mean:

- *Every A is a B*: anything that is an A is also a B.
- *Every A that is also a B is a C*: anything that is both an A and a B is also a C.
